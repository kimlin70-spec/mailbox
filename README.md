# 메일 백업 (MailBackup)

회사 웹메일(Exchange)의 메일을 내 PC에 복사해 두는 Windows 프로그램입니다.
서버에서는 **읽기만** 하며, 실행 후에도 웹메일은 그대로입니다.

## 1. 내려받기 (인터넷이 되는 곳에서)

1. <https://github.com/kimlin70-spec/mailbox/releases/latest> 를 엽니다.
2. `MailBackup.exe` 를 눌러 내려받습니다. 설치는 필요 없습니다.

## 2. 실행하기 (업무망 랜선을 꽂은 뒤)

1. `MailBackup.exe` 를 더블클릭합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누릅니다. (새 버전을 받을 때마다 뜰 수 있습니다)
2. 아이디(메일 주소 또는 `TOAMASINA\아이디`)와 비밀번호를 입력합니다.
3. **백업 시작**을 누릅니다.
   - 매일 돌릴 때는 **빠른 실행: 최근 7일** 을 체크하면 최근 메일만 확인해 더 빨리 끝납니다.
     체크 여부와 일수는 다음 실행 때도 기억합니다.
   - 한 달에 한 번쯤, 또는 일주일 넘게 쉰 뒤에는 체크를 풀고 전체로 한 번 실행해 주세요.
4. 끝나면 **저장 폴더 열기**를 눌러 확인합니다.

## 저장되는 곳

```
바탕화면\MailBackup\
  원본\받은편지함\(하위폴더)\YYYY-MM\날짜_시분_보낸사람_제목.eml   ← 메일 원본 (첨부 포함)
  원본\보낸편지함\YYYY-MM\...
  텍스트\YYYY-MM\대화제목.md       ← 같은 대화를 시간순으로 묶은 텍스트 (마지막 메일 날짜 기준)
  대화목록.csv                      ← 전체 대화 목록 (엑셀로 열기)
  상태\                            ← 이미 받은 메일·변환한 메일 목록 (지우면 처음부터 다시)
  로그\backup_날짜.log              ← 시각·폴더·건수·오류 이름만 기록
```

- 다시 실행하면 이미 받은 메일은 건너뛰고 새 메일만 받습니다.
- 중간에 멈추거나 끊겨도 다시 시작하면 이어서 받습니다.
- 서버에서 메일을 지워도 PC에 받아 둔 사본은 남습니다.
- 저장 위치는 창 아래의 **저장 위치 바꾸기**로 바꿀 수 있습니다. 이미 받은 메일은 자동으로
  옮겨지지 않으니, 이어서 받으려면 예전 폴더 내용을 새 폴더로 직접 옮겨 주세요.
- **OneDrive 등 클라우드와 동기화되는 폴더에 저장하면 회사 메일이 개인 클라우드로 올라갑니다.**
  바탕화면이 OneDrive 에 연결된 PC 에서는 프로그램이 경고를 띄웁니다. 그때는
  `C:\MailBackup` 처럼 동기화되지 않는 폴더를 골라 주세요.
- 디스크 여유 공간이 500MB 아래로 내려가면 받기를 멈춥니다.
- 같은 저장 폴더로 프로그램을 두 개 동시에 돌릴 수 없습니다.

## 텍스트 사본

- **백업 시작**을 누르면 백업이 끝난 뒤 자동으로 만들어집니다.
- **텍스트 사본만 만들기**는 서버에 연결하지 않고(로그인 없이) 이미 받은 메일로만 만듭니다.
- 변환은 이 PC 안에서만 이루어지며 외부 서비스에 연결하지 않습니다.
- **첨부 파일은 꺼내지 않습니다.** `.md` 에는 첨부 파일명과 원본 메일(`.eml`) 위치만 적습니다.
  첨부를 보려면 그 `.eml` 을 메일 프로그램으로 여세요. (메일에 섞여 온 위험한 파일이
  바로 실행 가능한 형태로 PC 에 놓이지 않게 하기 위함입니다.)
- 이전 메일 인용은 그 아래 모든 줄이 같은 대화의 앞선 메일에 실제로 있을 때만 지웁니다.
  서명·면책 문구를 포함해 그 밖의 본문은 그대로 둡니다.
- 새 메일이 오면 해당 대화 파일과 `대화목록.csv` 가 갱신됩니다.
  - `.md` 파일을 직접 고쳐도 그 대화에 새 메일이 오면 다시 만들어지므로 고친 내용은 사라집니다.
  - `대화목록.csv` 를 엑셀에서 열어 둔 채로 실행하면 목록을 갱신하지 못합니다.

## 지키는 것

- 서버에 보내는 요청은 폴더 조회·목록 조회·메일 가져오기 세 가지뿐입니다 (`mailbackup/ews.py`).
  삭제·이동·수정·발송·읽음 상태 변경 코드는 없습니다.
- 비밀번호는 실행할 때마다 입력하며 어디에도 저장하지 않습니다. 작업이 끝나면 입력 칸에서도 지웁니다.
- 프로그램이 접속하는 곳은 `https://mail.ambatovy.mg/EWS/Exchange.asmx` 한 곳뿐이고,
  보안 인증서 검증을 끄지 않습니다. (인증서를 확인하는 과정에서 Windows 가 인증서 발급 기관에
  접속할 수 있습니다. 브라우저로 웹메일을 열 때와 같은 동작입니다.)
- 한 번에 최대 10통씩, 요청 사이에 1초씩 쉬며 받습니다.
- 로그에 비밀번호·메일 내용을 남기지 않습니다.

## 알아 둘 것

- 회사 서버의 접속 기록에는 계정, 이 PC 의 IP 와 컴퓨터 이름, 프로그램 이름 `MailBackup` 이 남습니다.
- 비밀번호를 여러 번 틀리면 회사 계정이 잠길 수 있습니다. 로그인에 실패하면 바로 다시 누르지 말고
  아이디와 비밀번호를 확인해 주세요.
- 내려받기 페이지의 exe 는 버전 번호가 올라갈 때만 바뀝니다. 창 제목의 버전 번호로 확인할 수 있습니다.
